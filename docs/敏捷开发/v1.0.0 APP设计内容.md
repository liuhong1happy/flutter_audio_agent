## 一、项目概述

基于 **sherpa-onnx** 的跨平台(Android / iOS)离线文本转语音演示应用。用户输入文本 → 归一化/分词 → 后台 isolate 逐块合成 → 顺序播放,并模拟流式 TTS(首词快速出声、逐词高亮、边合成边播放)。

- 本地目录:`D:/work2026/flutter_tts_demo`
- Gitee 远程:`git@gitee.com:liuhong1happy/flutter_tts_demo.git`
- 包名/应用标识:`top.ued17.tts`
  - ⚠️ 用户最初指定 `top.17ued.tts`,但 Android 包名段**不能以数字开头**(AGP/AAPT 均会拒绝),故调整为 `top.ued17.tts`。

### 3.2 合成页:聊天式界面

```
┌──────────────────────────────────────────┐
│ AppBar:合成 [状态胶囊:模型/未下载]        │
│  朗读气泡列表(历史累积,自动滚到底部)      │
│  ┌ 一次输入 = 一条气泡(整段文本) ┐        │
│  │ 正在读的词 高亮(科技蓝底+字)  │        │
│  │ 分词 0.012s·首词 0.045s·…    │ ← 耗时  │
│  └──────────────────────────────┘        │
│ 播放控制条:[⏯] 进度 停止                 │
│ 输入框(底部)…… [发送]                    │
└──────────────────────────────────────────┘
```

- **一次输入 = 一条气泡(整段文本)**,发送后输入框清空;再输入追加新气泡
- 气泡列表可滚动,**永远展示最新一条在最下方**
- **逐词高亮**(卡拉OK式):正在读的词用淡科技蓝底 + 科技蓝字 + 加粗,已读词弱化
- 点击气泡可**重新朗读**该条(原位播放,不追加)
- 气泡下方展示 5 项**耗时统计**(按秒、最多 3 位小数):分词/首词/合成/播放/总处理

## 四、核心功能

### 4.1 文本处理管线

```
原文 → TextNormalizer(num2text)→ 归一化文本(含 sourceMap)
     → splitWords 词级切分(标点=分隔符)
     → 分块策略(见 4.2)→ 后台 isolate 逐块 OfflineTts.generate
     → SequentialAudioPlayer 顺序播放;onSegmentStarted 启动词计时器
     → 气泡逐词高亮 + 自动滚动
```

### 4.2 分块策略(模拟流式,降低首词延迟)

1. **先按句末标点切句**(`。！？；;.!?…\n`),避免长句/跨句切块
2. **首句**:`1 + 4 + 10 + …` 渐进分组 —— 首块 1 词,合成极快,首个音频尽早播放;又不至于太碎
3. **后续句子**(≤10 词):**整句一块**,自然顺滑
4. **长句**(>10 词):按 **10 词**切分,末块为剩余

> 演进:早期为每句 `1+2+4` 导致句子割裂,后优化为首句渐进 + 后续整句。

### 4.3 逐词高亮(词级进度)

- sherpa-onnx **无词级时间戳** → 用启发式:按"段音频时长 ∝ 词字符权重"分配词时长
- 段开始播放 → 启动 60ms 周期计时器 → 推进**全局词下标** → 高亮该词
- 支持暂停/继续/重读时的词进度衔接

### 4.4 耗时统计(气泡下方)

| 指标 | 含义 |
|---|---|
| 分词 | 归一化 + 分词/分块处理时间 |
| 首词 | speak 开始 → 首个音频就绪(首词返回延迟) |
| 合成 | 全部块文本→音频的总合成时长 |
| 播放 | 音频总播放时长(块音频时长之和) |
| 总处理 | = 分词 + 合成 |

- 统一用 `Duration` 记录;**持久化统一毫秒整数**(`toJson/fromJson`),避免浮点精度丢失
- UI 按秒显示,秒后最多 3 位小数

### 4.5 模型下载管理 + 国内镜像

- 内置 5 个模型目录(GitHub release `tts-models`)
- **国内下载失败根因修复**:release 包此前缺 `INTERNET` 权限 → 已在主清单补上 + `usesCleartextTraffic`
- **多镜像自动回退**:手动镜像 → `ghfast.top`(实测可用)→ `ghproxy.net`/`gh-proxy.com`/`ghps.cc` → 直连兜底
  - dio 连接超时 10s,快速切换;下载后校验 bzip2 魔数 `BZh`,防止镜像返回 HTML 错误页
- 存储权限:**无需添加**(下载到应用私有目录 `app_flutter/`)

### 4.6 历史持久化(flutter_dva)

- `settings` / `downloads` / `history` 三个模型 + `ReduxPersistor`
- 聊天气泡历史(原文/归一化/毫秒耗时)持久化,App 重启后仍显示
- 用法对齐 masrobo neme-ai-app:`dva.start(app, callback, waitCallabck:true)` 回调里建 persistor 并 `persist()`,之后统一初始化 `AppDependencies.instance`

### 4.7 依赖注入(单例)

- `AppDependencies.instance` 单例访问器 + `resetInstance()`(测试)
- `init()` 幂等
- 启动时序:initDva → persistor.persist() → AppDependencies.instance.init() → runApp(app())
