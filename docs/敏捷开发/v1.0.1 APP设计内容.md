## 一、版本概述

v1.0.0 是一个**纯离线 TTS** 演示:输入文本 → 归一化/分词 → 后台 isolate 合成 → 顺序播放,带逐词高亮。
v1.0.1 把它扩展成一个**语音对话应用** —— 在 TTS 之外引入离线 ASR、VAD、声纹识别、声音克隆,以及唯一一个
联网组件(在线 LLM)。本版本同时收口了声纹能力的第二轮扩展(双模型 / 门禁 / 按人切音 / 写操作认证)。

v1.0.1 相对 v1.0.0 的三块增量:

| # | 增量 | 性质 |
|---|---|---|
| 1 | **语音对话**(音频 / 文本双模式) | 新增核心页 + 编排状态机 |
| 2 | **声音克隆**(PocketTTS 零样本) | 配置型能力,非独立 Tab |
| 3 | **声纹识别**(三件套 + 双模型 + 门禁 + 写操作认证) | 配置型能力,非独立 Tab |

一句话边界:**LLM 是唯一联网组件**;ASR / TTS / 克隆 / 声纹 / VAD 全部离线。

## 二、技术栈(相对 v1.0.0 的新增)

| 组件 | 方案 | 说明 |
|---|---|---|
| 语音识别 | `sherpa_onnx` `OfflineRecognizer` | Paraformer(默认)/ SenseVoice(多语种 + 情绪) |
| 语音活动检测 | `sherpa_onnx` `VoiceActivityDetector` | Silero VAD,16kHz,常开麦克风分段 |
| 声纹识别 | `sherpa_onnx` `SpeakerEmbeddingExtractor` + `SpeakerEmbeddingManager` | 192 维嵌入,3D-Speaker 两个模型可选 |
| 声音克隆 | `sherpa_onnx` `OfflineTts` PocketTTS | 零样本,仅需 3–10s 参考音频,无需参考文本 |
| 录音 | `record ^7.1.1` | 流式 PCM16(对话)/ WAV 落盘(克隆参考) |
| 在线 LLM | `dio` 流式 SSE | OpenAI 兼容,DeepSeek / Moonshot / 智谱 / 通义千问 + 自定义 |
| 会话历史 | `sqflite` | SQLite,`version`+`onUpgrade` 版本化迁移,分页 |
| 设备认证 | `local_auth ^3.0.2` | 保护声纹档案的写操作,`biometricOnly: false` 允许 PIN 兜底 |

> 隔离区铁律沿用 v1.0.0:所有 sherpa 类是 FFI 原生,**必须在后台 isolate 中 `initBindings()` 后使用**,
> 主 isolate 不得调用;音频跨 isolate 用 `TransferableTypedData` 零拷贝。

## 三、UI 设计

### 3.1 导航变化:3 Tab → 3 Tab(内容重排)

v1.0.0 是「合成 / 模型 / 设置」;v1.0.1 移除「模型」Tab,模型下载**并入设置页各分类子页**,
底部变为「合成 / 对话 / 设置」,`IndexedStack` 常驻(切 Tab 不中断播放)。

### 3.2 对话页(第 2 Tab)

```
┌──────────────────────────────────────────────┐
│ [历史]      音频 ⇄ 文本        [设置]         │
│ ○ 聆听中   ○ 当前说话人:张三    [🔇] [🔊声音] │ ← 状态栏
│                                              │
│           聊天气泡(用户徽章 / 流式助手文本)   │
│                                              │
│        [ 开始对话 / 停止 ]                    │
└──────────────────────────────────────────────┘
```

- **音频模式**:语音 → ASR → 声纹 → LLM → TTS 语音回复,仅显示最后一轮
- **文本模式**:打字 → LLM 纯文本回复(不转 TTS),显示全部历史
- 未就绪时显示**初始化卡片**(三件套勾选 + 一键下载 + 进度),就绪后换成对话视图
- 长按气泡删除单条;Header 左侧进历史页、右侧进设置

### 3.3 设置页(两级)

首页为大类 ListItem:语音合成 / 语音识别 / VAD / **声纹识别** / 大模型 / 通用。
各子页配置参数 + **各自模型下载**;通用页含清理缓存。

声纹识别子页含:当前声纹模型(只读)+ 声纹阈值滑块 + **声纹门禁开关** + **设备认证开关** +
注册/管理入口 + 声纹模型下载列表。

### 3.4 声纹管理页

顶部为当前模型只读文字 + 模型下拉(有多个已下载声纹模型时出现)+ "另有 N 位注册在「X」下"提示;
下方列表只显示**当前模型**的档案,每条可绑定克隆音(`record_voice_over` 图标)或删除。
右上角 `搜索` 图标打开**测试识别**弹窗(弹窗内显示"当前声纹模型:X"——"录了却认不出"多半是模型对不上)。

### 3.5 注册说话人页

声纹模型下拉(选完写回设置 = 记住上次选择)+ 名字 + 备注 + 圆形居中录音按钮(每段 3 秒,建议 2–3 段)+ 保存。
支持连续注册多个。页面用 `SingleChildScrollView` + `minHeight` 约束 + `IntrinsicHeight`,保证键盘弹出时不溢出。

## 四、核心功能

### 4.1 对话编排状态机

```dart
enum ConversationPhase { idle, listening, asr, identifying, thinking, speaking, error }
// idle --开始对话(权限 + mic 流 + VAD)--> listening
// listening(VAD 常开)--> identifying --> [门禁] --> asr --> thinking(LLM 流)--> speaking(TTS,停 mic)--> listening
```

每轮 `_handleSegment`:

1. **声纹识别说话人**(`identify`)
2. **门禁拦截**(若开启且未识别到注册者 → 拒绝,直接返回)
3. ASR 转写(空文本忽略回 listening)
4. 追加用户消息(单一时间线,落 SQLite)
5. 停麦(防自听反馈)→ LLM 流式
6. 分块合成 → 按所选发音播放 → 播完自动恢复聆听

> **顺序是刻意的**:声纹识别只需要音频段、不需要文本,放在 ASR 之前后,门禁拒绝时**根本不触发
> ASR + LLM 两次推理** —— 拒绝比放行便宜。这是 v1.0.1 相对早期实现的一处优化。

### 4.2 声纹识别:双模型 + 分桶 + 跨模型并集

- **两个模型**:3D-Speaker `eres2net_base`(默认)与 `campplus_zh-cn-common`,均为 16kHz、**192 维**。
  用户在注册页选择,选择写回设置(即"记住上次选择")。
- **档案按模型分桶**:`Map<modelId, Map<name, profile>>`。原因是两个模型的**嵌入空间不通用** ——
  而且两者维度相同,混用**不会报错**,只会让识别分数变成噪音(最危险的一类静默错误)。
- **识别是跨模型并集**:对每个"有档案且已下载"的模型各跑一遍(各提取各的嵌入,因为向量不可跨模型比较)。
  多个模型匹配到不同名字时以**当前模型**为准。好处是"在哪个模型下注册都认得出";代价是识别时可能
  加载两个 onnx(没有档案的模型不加载,不白耗算力)。
- **引擎按 modelId 分槽**:`SpeakerEmbeddingExtractorConfig` 只接受单个模型路径,多模型必须多个
  extractor 实例。引擎 7 个方法全部要求显式 `modelId`,槽不存在就报错,**绝不回落到"当前某个"模型**。
- **同步顺序是硬约束**:`load` 会无条件重建该槽的 manager,所以"把档案灌进 manager"必须发生在 load
  **之后**(此时目标是空 manager,全量写入不会重复注册)。Dart 侧读不到 manager 内部状态,做不了增量同步。
- 读取档案(`ensureStoreLoaded`)与加载 onnx 分开:管理页要在冷启动就显示已注册的人,不该为看列表去加载模型。
- **老数据迁移**:声纹档案新增 `modelId` 键,旧数据没有该键 → 一律归入
  `kLegacyVoiceprintModelId`(不能用 `byKind` 猜,否则有人重排目录就会把老档案迁进另一套嵌入空间)。

### 4.3 声音克隆 + 按说话人切音色

- PocketTTS 零样本克隆:录 3–10s 参考音频建立克隆音档案(参考 WAV 路径 + 采样率经 dva `clones` 持久化)。
- 对话发音二选一:**模型音色**(走共享 TTS 引擎)或**克隆音**(走 PocketTTS)。
- **按说话人切音色**:可把克隆音**绑定到某位说话人**,对话中谁说话就用谁的克隆音回话;没绑定则回落到
  全局设置。绑定入口在声纹管理页,绑定本身就是 opt-in,不另设开关。

### 4.4 对话声纹门禁

- 开启后只有声纹库中注册过的人能触发对话。未通过者:**不转写、不落库、不问 LLM**,只播本地合成的拒绝语。
- 拒绝语复用 `_speakReply`,因此天然继承了停麦防自听反馈与播完自动恢复麦克风。
- **fail-closed**:门禁开着但一个声纹都没注册时,`start()` 拒绝启动并在状态栏给出可见原因 ——
  放行等于没门禁,宁可拒绝也不给用户虚假的安全感。判据是"**任何**模型下注册过"(与跨模型并集识别对齐),
  否则只注册在另一个模型下的人会被误挡。

### 4.5 声纹写操作的设备认证

- 抽象成可注入的 `AppLockService`(测试用假实现),真实实现基于 `local_auth`。
- 守卫点:**注册**、**删除档案**、**声纹阈值滑块**。为什么重点守注册 —— **录入是信任根**:
  谁能录入,谁就能把自己加进白名单然后通过识别。
- `authenticate(biometricOnly: false)`:允许系统 PIN/密码兜底,否则没录指纹的设备直接锁死。
- **解锁会话**(默认 5 分钟):必须有,否则连续注册多个人要反复按指纹,滑块之类的高频操作完全不可用。
- **守卫要真拦,不能只弹**:滑块在 `onChangeStart` 弹认证,`onChanged` 里同步检查解锁状态,**没通过就不落值**。
  只弹认证不拦写入等于没守。
- 设备认证不可用(无指纹也无 PIN / 平台无实现):弹说明对话框,由用户**显式**关闭该保护才继续,**绝不静默放行**。

### 4.6 会话历史:单一时间线 + SQLite

相对 v1.0.0 的 dva 历史,改为 **SQLite**(`version` + `onUpgrade` 版本化迁移),支持分页「加载更早」。
多说话人共用一个时间线,用户消息带说话人徽章,不再按说话人分桶。

### 4.7 模型目录泛化

`TtsModel` 增加 `kind`(tts / asrParaformer / asrSenseVoice / speaker / pocket / vad)、
`downloadFormat`(tarBz2 / rawFile)、`rawFileName`;resolver 与下载器按 kind 分支 ——
声纹与 VAD 是**裸 onnx**,必须跳过 bzip2 魔数校验与解压。

## 八、安全边界与已知事项

### 8.1 ⚠️ 声纹不是安全因子

门禁与录入认证都是**便利性/礼貌性防护,不是安全边界**。四条具体理由:

1. **可重放** —— 3 秒录音即可通过,而本应用的采样恰好就是硬编码 3 秒(`record_samples.dart`),门槛一致。
2. **可合成** —— 本应用自带 PocketTTS 零样本克隆,拿到样本即可合成授权人声音。
3. **判定是模糊的** —— 192 维嵌入的余弦阈值是同人/异人的权衡点,不是密码学的对错。
4. **嵌入明文落盘** —— 经 dva `ReduxPersistor` 持久化(非 Keystore/Keychain),本机读出即可注入他人嵌入冒充。

结论:对话内容会发给第三方 LLM,若涉及敏感信息,**不要**把声纹当作唯一门禁。
